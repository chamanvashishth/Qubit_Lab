# SIH26140 — Member 1 Frontend
Next.js + TypeScript + Tailwind CSS frontend starter for the AI-Based Interactive Quantum Algorithm Learning Platform.

## Run
1. Install Node.js 20+.
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:3000`

## Routes
- `/login`
- `/dashboard`
- `/learn`
- `/circuit-lab`
- `/quiz`

## Production integration
Replace the demo login with JWT/OAuth, connect dashboard data to backend APIs, add persistent state, and connect the circuit simulator/Qiskit service.
